# Prompt 08 — Visual QA

Compare the implementation against the reference at identical
desktop viewport dimensions.

Analyze:

- overall geometry
- header
- listing header
- photo gallery
- typography
- spacing
- colors
- buttons
- icons
- booking card
- sticky elements
- Photo Tour
- Lightbox
- animations

Identify the top 10 visual differences.

Rank them by impact.

Then implement the fixes starting with the highest-impact mismatch.
