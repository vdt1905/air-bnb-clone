# Phase 3 — Asset Analysis

Analyze the reference:
https://airbnb-clone-umber-two.vercel.app
We are creating an independent implementation.
Do NOT copy source code.
Create an asset inventory required to reproduce the visual result.
Identify:
- property images
- gallery images
- host/avatar image
- logo
- icons
- map/location visuals
- fonts
- other visible assets
For each asset document:
- purpose
- location
- approximate dimensions
- aspect ratio
- cropping
- object-position
- whether it repeats
- whether it appears in Photo Tour
- whether it appears in Lightbox
Also identify any assets that can be recreated using CSS or an
icon library instead of image files.
