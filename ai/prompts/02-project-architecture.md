# Prompt 02 — Project Architecture

Based on the reference analysis, design a maintainable full-stack
project.

Frontend:
- React
- Vite
- Zustand
- Tailwind CSS

Backend:
- Node.js
- Express
- Controllers
- Services
- Models
- Routes
- Middleware

Define:

- directory structure
- component hierarchy
- Zustand stores
- API endpoints
- frontend/backend responsibilities
- data flow

Keep the implementation focused on the assignment.

Do not introduce unnecessary infrastructure.
