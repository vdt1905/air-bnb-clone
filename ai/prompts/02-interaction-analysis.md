# Phase 2 — Interaction Analysis

Using the reference:

https://airbnb-clone-umber-two.vercel.app or original website

and the existing:

docs/reference/REFERENCE_ANALYSIS.md

create a detailed interaction specification.

Do not write application code.

Focus exclusively on observable behaviour.

## Document

### Listing Page

For every interactive element specify:

- trigger
- initial state
- resulting state
- animation
- transition
- whether URL changes
- whether a modal opens
- whether scroll is affected
- keyboard behaviour

Cover:

- header controls
- search
- save
- share
- gallery
- Show All Photos
- amenities
- description
- booking controls
- host controls
- footer interactions

### Photo Tour

Document:

- how it opens
- how it closes
- scrolling
- image click behaviour
- hover behaviour
- keyboard behaviour
- focus behaviour
- body scroll behaviour

### Lightbox

Document:

- open
- close
- next
- previous
- counter
- Escape
- ArrowLeft
- ArrowRight
- focus trapping
- focus restoration
- body scroll locking
- transitions

## Output

Create:

docs/reference/INTERACTION_SPEC.md

Use tables where useful.

Do not invent behaviour that is not observable in the reference.
